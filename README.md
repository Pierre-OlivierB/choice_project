# La maison de l'oubli

Prototype narratif interactif construit avec React et Vite.

Le joueur choisit un personnage, explore une scene d'horreur contemporaine,
prend des decisions, effectue des jets de caracteristiques, gere un inventaire
simple, puis recupere un prompt final base sur son parcours.

## Installation

```bash
npm install
```

## Lancer le projet

```bash
npm run dev
```

## Verification

```bash
npm run validate:story
npm run test
npm run lint
npm run build
```

## Documentation

- `master_plan.md` : vision, roadmap et etat d'avancement.
- `architecture.md` : architecture applicative.
- `fiche_design.html` : fiche design (couleurs, typographie, composants, illustrations).
- `sprint1.md` a `sprint6.md` : suivi des sprints.
- `narrative_guide.md` : guide d'ecriture du scenario.
- `scenario_audit.md` : audit du contenu narratif.
- `recherches.md` : recherches UX et pistes d'amelioration.
